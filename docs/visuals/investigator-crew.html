Investigator Crew

A three-agent CrewAI system that investigates an art theft. Built in one day on SAP Business Technology Platform, deployed to Cloud Foundry, and called from SAP Joule.

SAP Joule Generative AI Hub SAP-RPT-1 Grounding Service SAP AI Launchpad Cloud Foundry Business Application Studio Python CrewAI LiteLLM A2A protocol

One request, end to end

What happens between asking Joule and getting a verdict. The crew run takes two to five minutes.

  1. Joule routes the request

    The investigate_function sends an agent-request to the remote agent behind INVESTIGATOR_AGENT.

  2. The A2A server accepts it

    server.py reports working, reads the suspect names, and starts the crew in a worker thread.

  3. The Appraiser values the loss

    It sends the stolen-items table to SAP-RPT-1, which predicts the missing insurance values and category.

  4. The Analyst reads the evidence

    It queries the Grounding Service once per suspect and reports only what the documents say.

  5. The Detective decides

    It compares alibis, motives, opportunity and money across both reports, names the thief, and totals the insurance value.

  6. Joule shows the verdict

    The report returns as the A2A artifact investigation_result, and the task is marked completed.

What the agents work with

Two kinds of data, each matched to the model that handles it best.

Codebase

project/Python/starter-project/, empty at 11:30 and deployed by the afternoon.

main.pyLocal run. Starts the crew with the payload and the three suspect names.run
investigator_crew.pyThe two tools (call_rpt1, call_grounding_service), the three agents and tasks, and the sequential crew.run
config/agents.yamlRole, goal, backstory and model for each agent. Each goal ends with an instruction never to invent facts.run
config/tasks.yamlTask briefs. solve_crime takes the appraisal and evidence report as context.run
payload.pyThe stolen-items table with [PREDICT] placeholders for RPT-1.run
server.pyA2A server on FastAPI. Publishes the agent card "Investigate Art Theft" and a /health check.deploy
manifest.ymlCloud Foundry app on uvicorn, bound to the generative-ai-hub service.deploy
requirements.txtcrewai[a2a], a2a-sdk, litellm, sap-ai-sdk-gen.deploy
joule/da.sapdas.yamlJoule digital assistant project that loads the capability.joule
joule/investigator_capability/Capability, scenario and function. The function forwards the request to the remote agent and renders the reply.joule
